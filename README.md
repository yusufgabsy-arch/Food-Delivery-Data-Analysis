# 📊 Food Delivery Orders & ETA Logistics Analysis

## 📌 Project Overview

This project analyzes a **50,000-record food delivery dataset using Microsoft Excel**.

The purpose of the analysis is to understand food delivery operations, evaluate delivery performance, identify delays, analyze Estimated Time of Arrival (ETA), and generate data-driven insights that can support logistics and operational decision-making.

All data cleaning, analysis, calculations, visualizations, and dashboard development were completed in **Microsoft Excel**.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze food delivery order trends.
* Evaluate delivery performance.
* Analyze Estimated Time of Arrival (ETA).
* Identify delayed deliveries.
* Examine the relationship between delivery distance and delivery time.
* Calculate key logistics performance indicators (KPIs).
* Identify operational trends and inefficiencies.
* Create an interactive Excel dashboard.
* Provide recommendations based on the analysis.

## 📈 Excel Analysis

The analysis was divided into several areas.

### 1. Order Analysis

Analyzed:

* Total number of orders
* Order distribution
* Order trends
* Orders by location
* Orders by relevant categories

### 2. Delivery Performance

Analyzed:

* Average delivery time
* Delivery performance
* On-time deliveries
* Late deliveries
* Delivery performance by location
* Delivery performance by distance

### 3. ETA Analysis

Compared estimated delivery time with actual delivery performance.

This analysis helps identify:

* ETA accuracy
* Delivery delays
* Areas where estimated delivery times may need improvement

### 4. Distance Analysis

Analyzed delivery distance and its relationship with delivery time.

This helps answer:

> Does delivery distance affect delivery performance?

### 5. Delay Analysis

Identified patterns in delayed deliveries, including:

* Number of delayed orders
* Percentage of delayed orders
* Locations with higher delays
* Distance ranges associated with delays
* Delivery-period trends

## 📊 Key Performance Indicators

The Excel dashboard includes important logistics KPIs such as:

| KPI                       | Description                                             |
| ------------------------- | ------------------------------------------------------- |
| Total Orders              | Total number of orders analyzed                         |
| Average Delivery Time     | Average time required to complete deliveries            |
| Average ETA               | Average estimated delivery time                         |
| On-Time Delivery Rate     | Percentage of orders delivered within the expected time |
| Late Delivery Rate        | Percentage of delayed deliveries                        |
| Average Delivery Distance | Average distance covered per delivery                   |
| Cancellation Rate         | Percentage of cancelled orders                          |

## 📊 Excel Dashboard

An Excel dashboard was created to present the analysis in a simple and interactive format.

The dashboard contains:

* KPI cards
* Order volume analysis
* Delivery performance charts
* ETA analysis
* Delay analysis
* Distance analysis
* Location performance
* Interactive filters/slicers where applicable

The dashboard allows users to quickly understand the overall performance of the delivery operation.

## 🔍 Key Questions Answered

The analysis was designed to answer the following questions:

1. How many orders were processed?
2. What is the average delivery time?
3. What percentage of deliveries were completed on time?
4. What percentage of deliveries were delayed?
5. How accurate are the estimated delivery times?
6. Does delivery distance affect delivery time?
7. Which locations have higher delivery delays?
8. What periods experience higher order volumes?
9. Where are the major operational challenges?
10. What actions could improve delivery performance?

---

## 💡 Business Recommendations

Based on the analysis, the following areas can be considered for operational improvement:

* Improve ETA calculations using historical delivery data.
* Monitor locations with frequent delivery delays.
* Improve route and delivery planning.
* Increase operational resources during high-demand periods.
* Monitor delivery distance and delivery-time patterns.
* Track delivery KPIs regularly.
* Use historical performance data to support logistics planning.
